# Academic Planner & Study Analytics

## Project Overview

Academic Planner & Study Analytics is a Python-based project designed to help students organize their subjects, monitor academic performance, and plan their daily study time.

## Features

- View an academic dashboard with overall performance statistics.
- Add and delete subjects.
- Track current grades and target grades.
- Calculate grade gaps and academic priorities.
- Update daily study hours.
- Generate a smart study plan based on subject priorities.
- Record and review grade progress over time.
- Visualize academic performance using charts.
- Save academic data using JSON.

## Technologies Used

- Python
- Jupyter Notebook
- JSON
- Matplotlib

## Purpose

The purpose of this project is to explore how Python can be used to organize academic data, analyze student performance, and support effective study planning.

## Project Files

- `Academic_Planner_Study_Analytics.py` — Python source code.
- `Academic_Planner_Study_Analytics.ipynb` — Jupyter Notebook version.

## How to Run

Run the Python file in a Python environment with Matplotlib installed.

Alternatively, open the Jupyter Notebook in a compatible environment and execute the cells in order.
